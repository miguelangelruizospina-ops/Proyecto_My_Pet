Problemas habituales

No puedo iniciar sesión: verifica el correo y la contraseña y usa la misma dirección localhost para abrir la aplicación.

No se guarda un registro: revisa el mensaje que aparece en el formulario; el correo no puede estar registrado previamente.

No cargan mascotas u otros datos: comprueba el estado de conexión y que el servidor MySQL esté iniciado.
